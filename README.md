# Bagus Mahmudie

Kumpulan proyek website dan aplikasi web, mulai dari company profile hingga aplikasi administrasi, e-commerce, dan manajemen proyek.

Teknologi yang digunakan dalam proyek-proyek ini antara lain PHP, Laravel, Vue, Inertia.js, Eleventy, Tailwind CSS, dan MySQL.
