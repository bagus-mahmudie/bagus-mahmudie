# Project artwork

Original images are stored in `originals/` and copied from the corresponding project repositories. `sources.json` records source paths and file hashes. Display SVGs embed those images with a neutral background so the marks remain visible in both GitHub themes.

Project Management does not have a custom logo: its icon is the existing Laravel starter SVG from `ApplicationLogo.vue`, exported with a red fill. Logos identify the projects; ownership and trademark rights remain with their respective owners.
